# 🌾 AGRO.MAGAZ | Інтелектуальний Агрохаб, Лабораторія Точного Господарства та Інтернет-Магазин Case IH

**AGRO.MAGAZ** — сучасна цифрова агроплатформа національного масштабу, що об'єднує живий ринковий моніторинг (24h парсери без заглушок та симуляцій), повну інтегровану лабораторію точного землеробства (на основі **Ibonarium.AGRO Ultimate Terminal**) та електронний шоурум сільгосптехніки Case IH.

## 🌟 Архітектура та функціональні модулі

### 1. 🇺🇦 Жива 24h стрічка новин Агро Україна
- Автоматичний парсер новин виключно за останні 24 години (*Latifundist.com, AgroPortal.ua, Google News Ukraine, МінАгро/ДАР*).
- Динамічний лічильник віку публікацій (*"15 хв тому", "2 год тому"*).
- Категоризація та фільтрація: **Всі, Експорт, Ринок, Фінанси, Техніка**.
- Прямі активні посилання на першоджерела.

### 2. 🌐 Global Agro News (EN, 24h — Без заглушок)
- 100% реальні англомовні новини світового агробізнесу за 24 години без мок-заглушок.
- Фільтри за темами: **All Feeds, Markets, Crops, Trade, AgTech**.

### 3. 📈 Бігучий рядок (Ticker) — тільки офіційні дані, нуль симуляцій
- **Офіційний курс НБУ**: пряма інтеграція з API Національного банку України (`USD`, `EUR`, `PLN`) в режимі реального часу (`bank.gov.ua`, `access-control-allow-origin: *`).
- **Реальна динаміка за 7 днів**: історичні офіційні курси НБУ (окремий запит на дату) — чесні `%` без вигаданих трендів.
- **Спарклайни з реальної історії НБУ**: точки 12/10/8/6/4/2 днів тому + сьогодні — тільки фактичні котирування.
- **Котирування зерна (СРТ/CBOT/Matif), нафти та пального — виведено**: безкоштовного офіційного API без CORS-блокування не існує; симуляцію не публікуємо. Блок «Джерела даних» на сторінці документує це відкрито.
- **Повна відсутність `Math.random()`** у бізнес-даних: агро-індекс та журнал подій рахуються виключно з реальних вхідних даних (Open-Meteo, Sentinel-2 NDVI, НБУ).

### 4. 🛰️ Агрономічна Лабораторія Точного Господарства (Ibonarium Integration)
Повна інтеграція науково-дослідного терміналу **Ibonarium.AGRO**:
- **Інтерактивна карта областей України (Leaflet GeoJSON)**:
  - 25 адміністративних областей з hover-підсвіткою та плавним переміщенням (`flyTo`).
  - Кешований локальний GeoJSON (`data/ukraine.geojson`) для миттєвого завантаження офлайн та при повільному інтернеті.
  - Клік по будь-якій області автоматично підтягує точні географічні координати та оновлює всю телеметрію Open-Meteo саме для цього регіону.
  - Кнопка скидання «Вся Україна (Глобально)».
- **Супутниковий індекс вегетації (NDVI)**:
  - Супутникова композитна карта посівів з градієнтною шкалою біомаси (від 0.2 стресу до 0.9 максимальної вегетації).
  - Телеметричні індикатори хлорофілу та фази росту посівів.
- **Експертний статус та агрономічні рішення (4 картки Live)**:
  - **ТЕРМІЧНИЙ СТАН ҐРУНТУ**: оцінка готовності до сівби на основі датчика температури на глибині 6 см (поріг ≥ 8.5°C).
  - **ВІКНО ВНЕСЕННЯ ЗЗР**: автоматичний розрахунок деривації та знесення крапель за швидкістю вітру (поріг < 14 км/год).
  - **ДЕФІЦИТ ВОЛОГИ**: пошарова діагностика зволоження посівного шару 0-1 см та кореневої зони.
  - **ТЕРМІЧНИЙ РИЗИК / СТРЕС**: відстеження ризику нічних приморозків (≤ 2°C) або теплового стресу (≥ 32°C).
- **5 модульних вкладок польової телеметрії (Open-Meteo Professional API)**:
  1. ☁️ **Атмосферний моніторинг** (8 показників): температура, відчувається, вологість, тиск, швидкість вітру, пориви, точка роси, хмарність.
  2. 🌾 **Пошаровий стан ґрунту** (6 показників): поверхня 0 см, посівний горизонт 6 см, кореневий 18 см, глибокий 54 см, об'ємна волога 0-1 см та 9-27 см.
  3. ☀️ **Радіаційний баланс та Вегетація** (8 показників): сумарна сонячна радіація, пряма, дифузна, ET0 FAO випаровування, дефіцит тиску водяної пари VPD, ФАР (PAR Photosynthesis), зволоження листя (Leaf Wetness), сума сонячної енергії.
  4. 🧬 **Агрономічні індекси** (6 показників): GDD (сума ефективних температур, база 5°C), Heat Index, добові опади, потік енергії, поглинання CO₂ (Carbon Sink), комплексний Bio Score.
  5. 🚛 **Операційні показники регіону** (8 показників): кондиційна вологість зерна при збиранні, модельована технологічна врожайність, рівень запиленості полів, завантаженість елеваторів, резерв палива, техніка в роботі, логістичний тиск, клас безпеки Ag-Rating.
- **Аналітичні графіки (Chart.js)**:
  - 📈 **Температура: Повітря vs Ґрунт (7-Day Real Trend)**: 100% реальні історичні та модельовані прогнози Open-Meteo на 7 днів (без захардкодних списків).
  - 💧 **Пошаровий профіль вологості (0-81 см)**: 5 реальних горизонтів (0-1см, 1-3см, 3-9см, 9-27см, 27-81см).
  - 🎯 **Радар польових агро-ризиків**: розрахунок 5 осей ризику (Посуха, Заморозки, Вітрова ерозія, Шкідники, Перезволоження) на основі фізичних датчиків.
